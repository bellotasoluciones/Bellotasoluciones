Política de privacidad

Información sobre el tratamiento de datos. Bellota no utiliza un formulario web ni una base de datos propia de consultas en el sitio revisado. Las consultas se coordinan por WhatsApp o email; esos proveedores procesan los mensajes según sus propias políticas.

1. Responsable y contacto

El sitio Bellota Soluciones Digitales es gestionado por Alexis Ojeda, persona humana que presta servicios de manera independiente. Domicilio informado: Avellaneda, Provincia de Buenos Aires, Argentina. CUIT informado: 20-37787991-1. Contacto: bellotasoluciones@gmail.com.

2. Qué datos se reciben

El sitio estático no ofrece un formulario de contacto. Si escribís por WhatsApp o email, el mensaje puede incluir tu nombre, datos de contacto, información que compartas sobre tu proyecto y comunicaciones posteriores. Se recomienda no enviar datos sensibles que no sean necesarios.

3. Finalidad

Los datos que compartas se usan para responder consultas, preparar presupuestos, coordinar y prestar servicios, documentar acuerdos y atender obligaciones legales o reclamos. No se declara una base de datos propia ni se prevé vender datos personales.

4. Proveedores externos y analítica

El código del sitio revisado incluye el rastreador web de Metricool y carga tipografías desde Google Fonts. Metricool y Google pueden recibir datos técnicos de conexión al cargar esos recursos. Los mensajes de contacto se gestionan mediante WhatsApp o email. Cada proveedor trata datos conforme a sus políticas y condiciones. Esta descripción debe actualizarse si cambia el código o la configuración de estos servicios.

5. Conservación y seguridad

Los mensajes pueden permanecer en las cuentas y dispositivos utilizados para WhatsApp y email. Se conservarán durante el tiempo necesario para atender la consulta, gestionar la relación comercial y cumplir obligaciones legales. No se afirma que exista una base de datos central propia. La seguridad también depende de la protección de las cuentas y dispositivos de comunicación.

6. Derechos de las personas

Podés solicitar acceso, actualización, rectificación o supresión cuando corresponda escribiendo a bellotasoluciones@gmail.com. La solicitud se analizará de acuerdo con la Ley 25.326 y sus excepciones. También podés consultar a la Agencia de Acceso a la Información Pública en su sitio oficial.

7. Cambios

Esta política se actualizará si cambian las herramientas, los canales de contacto o las prácticas de tratamiento de datos.
